
# Confeitaria Saturno

A responsive website I built for a bakery based in Brazil.

The idea was to create a simple and organized way for customers to explore the bakery's products and get in touch.

### Features

- Responsive layout for desktop and mobile
- Product catalog with different categories
- WhatsApp integration for customer inquiries
- Instagram integration
- Custom design and navigation

### Built With

- HTML
- CSS
- JavaScript
